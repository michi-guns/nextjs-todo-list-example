# Project Design Workspace

DWF Framework version: see `.framework/VERSION`.

## Start here

Project truth:

- `CONTEXT.md` — verified durable project/system facts
- `RULES.md` — mandatory project-specific constraints
- `decisions/PRODUCT.md` — accepted Product Decisions (`D-*`)
- `decisions/TECHNICAL.md` — accepted Technical Decisions (`TD-*`)
- `decisions/EDGE-CASES.md` — explicitly considered scenarios (`EC-*`)
- `decisions/OPEN-QUESTIONS.md` — unresolved facts (`OQ-*`)
- `decisions/OPEN-DECISIONS.md` — unresolved choices (`OD-*`)

Derived explanations:

- `concepts/` when present

Generated projections:

- `output/agent/PRD.md`
- `output/agent/SPEC.md`
- `output/human/PRD.md`
- `output/human/SPEC.md`

Framework machinery:

- `.framework/` — read-only during ordinary project work

Replace this bootstrap text with project-specific orientation while preserving the ownership map.
