# Source Guide — Refero

Website: https://refero.design/

## Role

Use Refero for curated real product interfaces, web-app composition, UI patterns, and user flows.

It is particularly useful for:

- SaaS and productivity interfaces
- dashboards and application shells
- tables, cards, sidebars, dialogs, and toolbars
- billing/settings/account surfaces
- search/filter patterns
- visual hierarchy within real product UIs
- comparing screen-level and flow-level approaches

## Best use

Start from the problem being solved, then inspect several references that handle comparable complexity.

When a direction is visually informed by Refero, describe the reusable system rather than aesthetic adjectives alone:

> Uses a strong type hierarchy and low-chrome surfaces so dense secondary controls remain discoverable without competing with the primary data.

## Access

Prefer a configured Refero MCP/native integration when available. Otherwise use browser/web access. If inaccessible, continue with other sources.

Do not assume current catalog size, pricing, or integration setup. Those are volatile and should be checked at runtime only when relevant.

## Avoid

- selecting examples only because they are visually polished
- turning the exploration into a collection of SaaS screenshots
- copying distinctive branding or compositions
- using one visual style across several directions and calling them separate hypotheses
