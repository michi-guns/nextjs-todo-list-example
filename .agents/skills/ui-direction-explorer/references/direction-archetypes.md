# Direction Archetypes

These are prompts for expanding the search space, not presets and not a requirement to choose one archetype per direction.

A direction should emerge from the product problem. Combine, adapt, or ignore archetypes as needed.

## Operational Control Center

Dense, fast, persistent context, high information visibility. Good hypothesis when expert users repeat tasks frequently and navigation cost matters.

Questions:

- What can remain visible instead of hidden behind navigation?
- Which actions deserve keyboard or bulk affordances?
- How can density remain scannable?

## Calm Workspace

Low cognitive noise, progressive disclosure, obvious next action. Good for occasional users or tasks where confidence matters more than throughput.

Questions:

- What can be hidden until relevant?
- How can secondary controls avoid competing with the primary task?

## Entity Explorer

Organize the surface around core domain objects: customer, device, transaction, order, project, etc.

Questions:

- Can related information/actions stay anchored to the selected entity?
- Would master-detail or contextual panels reduce navigation?

## Guided Workflow

Sequential, task-oriented, explicit progress and validation.

Useful for setup, onboarding, compliance, configuration, or rare high-consequence tasks.

## Search / Command First

The fastest path begins with search, command palette, or intent entry rather than browsing navigation.

Useful for large datasets, power users, or fragmented action spaces.

## Data Canvas

Charts, spatial relationships, timelines, maps, diagrams, or direct manipulation are the primary navigation/understanding mechanism.

Use only when visualization materially improves the task.

## Modular Dashboard

Composable sections optimized for monitoring multiple signals or workflows at once.

Question whether cards are truly independent modules or merely decorative containers.

## Table / Ledger First

Structured rows, columns, sorting, filtering, and comparison dominate. Strong for high-volume operational data.

Explore whether details belong inline, in a drawer, or on a dedicated route.

## Timeline / Activity First

Sequence and causality are the core organizing principle. Useful for audits, transaction histories, deployment/activity streams, and case management.

## Contextual Split View

Persistent list/canvas plus contextual details or inspector. Useful when users repeatedly inspect many entities without losing place.

## Document / Editorial

Typography and narrative hierarchy organize complex information with fewer containers. Useful when comprehension is more important than manipulation.

## Mobile-Native Task Flow

Bottom navigation, sheets, thumb-friendly primary actions, focused screens, and progressive drill-down.

Do not merely shrink a desktop dashboard.

## Tool / IDE-Like Workspace

Persistent panes, inspector panels, command actions, resizable regions, high state continuity. Appropriate for expert creation or operations products.

## Conversation / Assistant-Led

Intent and iterative guidance are primary. Use only when language interaction genuinely reduces complexity; avoid replacing simple deterministic controls with chat.

## Kiosk / Transactional

Large targets, constrained choices, strong confirmation, minimal distractions, rapid reset between sessions. Useful for POS, terminals, and public/shared devices.

## Divergence use

If the candidate pool is converging, use archetypes to ask "what would the opposite assumption look like?" rather than adding cosmetic variation.
