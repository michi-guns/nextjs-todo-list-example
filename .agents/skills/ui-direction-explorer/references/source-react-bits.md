# Source Guide — React Bits

Website: https://reactbits.dev/
Pro/Agent documentation: https://pro.reactbits.dev/

## Role

Use React Bits primarily for visual vocabulary, interaction, motion, expressive composition, and implementation ideas after a direction's UX hypothesis is clear.

Useful areas include:

- purposeful micro-interactions
- animated state transitions
- distinctive typography/background treatments
- expressive product or marketing surfaces
- application UI blocks when available
- design-direction material intended for coding agents

## Sequence rule

A predefined design style is not automatically a separate UX direction.

For example, "editorial," "terminal," and "minimal" can be useful visual languages, but they do not by themselves answer different product questions. Apply them only when they reinforce a direction's hierarchy, audience, workflow, or product character.

## Access

Use configured registry/MCP/agent tooling when available, or browse accessible documentation/examples. Some assets or guidance may depend on a commercial plan; never assume entitlement.

Check current docs for installation/setup rather than embedding volatile commands or plan details in this skill.

## Motion rule

Motion must communicate something useful, such as:

- spatial relationship
- state change
- feedback
- hierarchy
- continuity

Do not add animation merely to make one spike look more impressive than the others.

## Avoid

- visual-effects-first exploration
- forcing high-motion patterns into high-frequency operational tools
- using different effects as fake divergence
- adopting licensed written Agent Kit material verbatim into this skill
